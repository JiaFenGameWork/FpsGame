# 敌人系统使用说明

## 概述

敌人系统采用状态机模式，支持多种巡逻模式和攻击模式。核心设计理念是**灵活可选**，不强制要求所有敌人都有巡逻功能。

## 基类：BaseEnemyController

所有敌人都继承自 `BaseEnemyController`，它提供了：

### 可选组件
- **PatrolPoints**: 固定点巡逻时使用的巡逻点数组（可选）
- **patrolState**: 巡逻状态，可以是 `PatrolState`、`RandomPatrolState` 或不设置（可选）
- **attackState**: 攻击状态，根据敌人类型初始化不同的攻击状态（必需）

### 核心功能
- 状态机管理
- 异步寻路系统
- 地形检测
- 动画控制

## 三种巡逻模式

### 1. 固定点巡逻（PatrolState）

**适用场景**：需要在固定路线巡逻的敌人，如守卫

**使用方法**：
```csharp
public class EnemyControllerGuard : BaseEnemyController
{
    protected override void Awake()
    {
        base.Awake();
        
        // 使用固定点巡逻
        patrolState = new PatrolState(this, _animator, Movespeed);
        attackState = new RollingState(this);
    }
    
    protected override void Start()
    {
        base.Start();
        StateMachine.ChangeState(patrolState);
    }
}
```

**注意**：需要在 Unity Inspector 中设置 `PatrolPoints` 数组

### 2. 随机巡逻（RandomPatrolState）

**适用场景**：在某个区域内随机游荡的敌人，如野生怪物

**使用方法**：
```csharp
public class EnemyControllerRandomPatrol : BaseEnemyController
{
    [Header("随机巡逻设置")]
    public float patrolRadius = 15f; // 巡逻半径
    
    protected override void Awake()
    {
        base.Awake();
        
        // 使用随机巡逻，不需要PatrolPoints
        patrolState = new RandomPatrolState(this, _animator, patrolRadius, Movespeed);
        attackState = new RollingState(this);
    }
    
    protected override void Start()
    {
        base.Start();
        StateMachine.ChangeState(patrolState);
    }
}
```

**特点**：
- 不需要手动设置巡逻点
- 在初始位置周围的指定半径内随机移动
- 自动处理到达目标点后的等待和重新生成目标

### 3. 不巡逻（patrolState = null）

**适用场景**：静止的敌人，如炮台、陷阱

**使用方法**：
```csharp
public class EnemyControllerTurret : BaseEnemyController
{
    private IState idleState;
    
    protected override void Awake()
    {
        base.Awake();
        
        // 不初始化patrolState
        idleState = new TurretIdleState(this, _animator);
        attackState = new RollingState(this);
    }
    
    protected override void Start()
    {
        base.Start();
        StateMachine.ChangeState(idleState); // 从待机状态开始
    }
}
```

**特点**：
- 不需要巡逻相关代码
- 可以实现自己的待机状态
- 其他状态会自动检测 patrolState 是否为 null

## 安全性保障

所有引用 `patrolState` 的地方都做了空值检查：

### RollingState（攻击状态）
```csharp
// 目标离开视野后，如果有巡逻状态则返回巡逻
if (enemyController.patrolState != null)
{
    enemyController.StateMachine.ChangeState(enemyController.patrolState);
}
```

### StaggerState（硬直状态）
```csharp
// 硬直结束后恢复到指定状态或巡逻状态
var targetState = _resumeState ?? _enemyController?.patrolState;
if (targetState != null)
{
    _enemyController.StateMachine.ChangeState(targetState);
}
```

## 现有敌人示例

### EnemyControllerBallRobot（使用固定点巡逻）
- 需要设置 `PatrolPoints`
- 在巡逻点之间移动
- 发现玩家后进入滚球攻击状态

### EnemyControllerRobot1（使用固定点巡逻）
- 同上

### EnemyControllerRandomPatrol（新：使用随机巡逻）
- 不需要设置 `PatrolPoints`
- 在指定半径内随机移动
- 可调整巡逻半径

### EnemyControllerTurret（新：不巡逻）
- 原地旋转搜索目标
- 发现玩家后攻击
- 适合固定炮台类型

## 创建新敌人的步骤

1. **继承 BaseEnemyController**
2. **在 Awake 中初始化状态**：
   - 选择巡逻模式（或不巡逻）
   - 初始化攻击状态
3. **在 Start 中设置初始状态**
4. **如果使用固定点巡逻，在 Inspector 中设置 PatrolPoints**

## 扩展建议

### 添加新的巡逻模式
实现 `IState` 接口，参考 `PatrolState` 或 `RandomPatrolState` 的实现

### 添加新的攻击模式
实现 `IState` 接口，参考 `RollingState` 的实现

### 添加新的状态类型
所有状态都实现 `IState` 接口，可以自由组合

## 注意事项

1. **寻路系统**：需要在 Inspector 中设置 `nav`（NavMeshAsset）和 `terrain`
2. **动画**：确保 Animator 中有对应的动画状态（如 `anim_Walk_Loop`, `anim_Idle_Loop_S`）
3. **玩家检测**：基类会自动查找 Tag 为 "Player" 的对象作为目标
4. **状态切换**：注意设置滞后量（hysteresis）防止边缘震荡

## 总结

这个系统的核心优势是**灵活性**：
- ✅ 支持多种巡逻模式
- ✅ 巡逻功能完全可选
- ✅ 易于扩展新的状态
- ✅ 自动处理空值，不会出错
- ✅ 代码复用性高

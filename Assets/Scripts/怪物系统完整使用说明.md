## 系统概述

这是一套**模块化、可扩展**的怪物AI系统，支持：

- ✅ **状态机驱动**：清晰的状态切换逻辑（巡逻/追逐/攻击/硬直）
- ✅ **异步寻路**：基于 Octree 的 3D 寻路，支持异步回调，不卡帧
- ✅ **动画事件**：通过动画片段事件精准控制射击时机、命中判定窗口、位移等
- ✅ **灵活巡逻**：支持固定点巡逻、随机巡逻、不巡逻（如炮台）
- ✅ **伤害接口**：统一的 `IDamageable` 接口，支持血条、受击反馈、死亡动画
- ✅ **对象池**：子弹等频繁生成对象使用对象池避免 GC
- ✅ **易于扩展**：新增怪物类型、新攻击方式只需继承/实现相应接口

## 快速开始：创建第一个怪物

### 第一步：准备资源

1. **模型与动画**：
   - 在 Unity 中导入怪物 3D 模型（带 Animator）
   - 确保 Animator Controller 包含动画状态：
     - `anim_Idle_Loop_S`（待机）
     - `anim_Walk_Loop`（行走）
     - `anim_Run_Loop`（奔跑，可选）
     - 攻击动画（如 `anim_open_GoToRoll`、`anim_Shoot` 等）

2. **地形与寻路**：
   - 场景中需要有 `Terrain` 组件
   - 需要烘焙 `NavMeshAsset`（Octree 寻路数据）

3. **玩家对象**：
   - 场景中必须有一个带 `Player` Tag 的对象
   - 建议玩家挂载 `CharacterState` 组件（实现 `IDamageable`）

### 第二步：创建怪物预制体

1. **创建基础 GameObject**：
   - 在场景中创建 `GameObject`，命名为 `Enemy_MyMonster`
   - 添加 `Animator` 组件，指定 Animator Controller

2. **添加核心组件**：
   ```
   MyMonster (GameObject)
   ├─ Animator
   ├─ CharacterState        ← 血量、血条、伤害接收
   ├─ EnemyControllerMyMonster ← 继承自 BaseEnemyController
   ├─ Collider (如 CapsuleCollider) ← 用于受击检测
   └─ (可选) Agent         ← 如果使用空间分区系统
   ```

3. **Inspector 配置**（`BaseEnemyController` 字段）：
   - **基础属性**：
     - `height`: 怪物高度（用于寻路）
     - `maxStepHeight`: 最大可跨越台阶（默认 0.5m）
     - `SightRange`: 视野范围（发现玩家距离）
     - `AttackRange`: 攻击范围
     - `Movespeed`: 移动速度
   
   - **组件引用**：
     - `terrain`: 拖入场景中的 Terrain
     - `nav`: 拖入烘焙好的 `NavMeshAsset`
     - `_animator`: 自动获取（或手动拖入）
   
   - **巡逻设置**（可选）：
     - `PatrolPoints`: 如果使用固定点巡逻，拖入多个空 Transform 作为巡逻点

4. **配置 CharacterState**：
   - `MaxHp`: 最大生命值
   - `healthBarHeight`: 血条高度偏移
   - `Deadmaterial`: 死亡溶解材质（可选）
   - `renderer`: 用于溶解动画的 MeshRenderer

### 第三步：编写控制器脚本

创建 `EnemyControllerMyMonster.cs`：

```csharp
using UnityEngine;
using UnityEngine.VFX;

public class EnemyControllerMyMonster : BaseEnemyController
{
    [Header("特效")]
    public VisualEffect AttackVFX; // 可选：攻击特效
    
    private float _attackHysteresis = 1.5f; // 状态切换滞后量
    private bool _isInAttackState = false;
    
    protected override void Awake()
    {
        base.Awake(); // 必须调用！初始化 Target、StateMachine、Animator
        
        // 初始化状态
        // 1. 巡逻状态（三选一）：
        //    - 固定点巡逻：
        patrolState = new PatrolState(this, _animator, Movespeed, autoSwitchToAttack: false);
        //    - 随机巡逻：
        // patrolState = new RandomPatrolState(this, _animator, radius: 15f, Movespeed);
        //    - 不巡逻：
        // patrolState = null;
        
        // 2. 攻击状态（根据怪物类型选择）：
        //    - 滚球攻击：
        attackState = new RollingState(this, AttackVFX);
        //    - 射击攻击：
        // attackState = new ShootingState(this, _animator, bulletPrefab, bulletSpawnPoint, ...);
        //    - 自定义攻击：
        // attackState = new MyCustomAttackState(this, ...);
        
        // 3. 追逐状态（可选）：
        ChaseState = new ChaseState(this, _animator, speed: 5f);
    }
    
    protected override void Start()
    {
        base.Start(); // 初始化 NePathFinder
        
        // 设置初始状态
        if (patrolState != null)
        {
            StateMachine.ChangeState(patrolState);
        }
        else
        {
            // 如果不巡逻，可以从待机状态开始
            // StateMachine.ChangeState(new TurretIdleState(this, _animator));
        }
    }
    
    protected override void Update()
    {
        base.Update(); // 驱动状态机
        
        // 控制器层级的状态切换逻辑
        CheckAttackRange();
    }
    
    private void CheckAttackRange()
    {
        if (Target == null || StateMachine == null) return;
        
        float distance = Vector3.Distance(transform.position, Target.position);
        
        // 进入攻击范围
        if (!_isInAttackState && attackState != null)
        {
            if (distance < SightRange - _attackHysteresis)
            {
                _isInAttackState = true;
                StateMachine.ChangeState(attackState);
            }
        }
        // 离开攻击范围
        else if (_isInAttackState && patrolState != null)
        {
            if (distance > SightRange + _attackHysteresis)
            {
                _isInAttackState = false;
                StateMachine.ChangeState(patrolState);
            }
        }
    }
}
```

## 核心组件详解

### 1. `BaseEnemyController`（怪物控制器基类）

**职责**：
- 管理状态机（`StateMachine`）
- 提供异步寻路接口（`RequestPathAsync`）
- 持有 Target（玩家）引用
- 动画事件入口（`AE_*` 方法）

**关键方法**：

```csharp
// 请求异步寻路
public int RequestPathAsync(Vector3 start, Vector3 end, Action<int, List<Vector3>> onDone)

// 取消寻路请求
public void CancelPathRequest(int requestId)

// 动画事件回调（在动画片段中调用）
public void AE_Shoot(int count = 1)              // 射击事件
public void AE_ShootMuzzle(int muzzleIndex)      // 指定枪口射击
public void AE(string eventKey)                  // 通用事件（新增）
public void AE_Int(int eventValue)               // 通用整数事件（新增）
```

**子类必须实现**：
- `Awake()`: 初始化状态（`patrolState`、`attackState`等）
- `Start()`: 设置初始状态
- `Update()`: 可选，控制器层级的逻辑（如状态切换条件判断）

---

### 2. `IState` 接口（状态接口）

所有状态必须实现此接口：

```csharp
public interface IState
{
    void OnEnter();  // 进入状态时调用（播放动画、初始化计时器）
    void Tick();     // 每帧更新（相当于 Update）
    void OnExit();   // 退出状态时调用（清理数据、停止协程）
}
```

**状态生命周期**：
```
ChangeState(newState) → 旧状态.OnExit() → 新状态.OnEnter() → 每帧调用 newState.Tick()
```

---

### 3. `IAnimationEventReceiver` 接口（动画事件接收者）**[新增]**

**用途**：让状态能接收通用动画事件，用于精准控制攻击窗口、位移、无敌帧等。

```csharp
public interface IAnimationEventReceiver
{
    void OnAnimationEvent(string eventKey);
    void OnAnimationEventInt(int eventValue);
}
```

**示例**：在动画片段中添加事件 → 函数名填 `AE`，参数填 `"HitStart"` → 当前状态的 `OnAnimationEvent("HitStart")` 被调用。

---

### 4. `CharacterState`（血量与伤害管理）

**实现接口**：`IDamageable`

**功能**：
- 血量管理（`CurrentHealth`、`MaxHealth`）
- 动态世界空间血条（受击后显示，自动隐藏）
- 受击事件（`OnTakeDamage`）
- 死亡事件（`OnDeath`）
- 死亡溶解动画（需要材质支持 `_DissolveAmount` 参数）

**接口方法**：
```csharp
void TakeDamage(AttackData attackData); // 受到攻击
void Die();                              // 死亡（销毁控制器、播放溶解动画）
```

---

### 5. `NePathFinder`（异步寻路）

**特点**：
- 基于 Octree 的 A* 算法
- 支持异步寻路（协程实现，每帧限制节点处理数量）
- RequestID 机制防止旧回调覆盖新请求
- 自动处理高度变化（台阶、斜坡、悬崖）

**使用方法**（在状态中）：
```csharp
// 1. 请求寻路
_pathRequestId = enemyController.RequestPathAsync(start, end, OnPathCallback);

// 2. 回调接收路径
private void OnPathCallback(int id, List<Vector3> path)
{
    if (id != _pathRequestId) return; // 忽略旧请求
    if (path != null && path.Count > 0)
    {
        // 寻路成功，沿路径移动
    }
    else
    {
        // 寻路失败
    }
}
```

## 状态库详解

### 1. `PatrolState`（固定点巡逻）

**适用场景**：守卫、有固定路线的怪物

**配置**：
- 需要在 Inspector 中设置 `PatrolPoints` 数组
- 怪物会按顺序在巡逻点之间移动

**构造函数**：
```csharp
public PatrolState(
    BaseEnemyController controller, 
    Animator animator, 
    float speed = 3f, 
    bool autoSwitchToAttack = true  // 是否自动切换到攻击状态
)
```

**特性**：
- 自动寻路到下一个巡逻点
- 到达后等待 2 秒再前往下一个点
- 支持卡住检测（1秒内移动<0.2m则跳到下一个点）
- 可选自动切换到攻击状态（发现玩家时）

---

### 2. `RandomPatrolState`（随机巡逻）

**适用场景**：野生怪物、在区域内游荡的敌人

**配置**：
- 不需要设置 `PatrolPoints`
- 在初始位置周围的指定半径内随机移动

**构造函数**：
```csharp
public RandomPatrolState(
    BaseEnemyController enemy, 
    Animator animator, 
    float radius = 10f,              // 巡逻半径
    float speed = 3f,
    string walkTrigger = "anim_Walk_Loop",
    string idleTrigger = "anim_Idle_Loop_S",
    bool autoSwitchToAttack = true
)
```

---

### 3. `ChaseState`（追逐状态）

**适用场景**：发现玩家后追逐，接近后切换到攻击状态

**特性**：
- 定期更新路径（玩家在移动）
- 支持自动状态切换（进入攻击范围/超出视野范围）
- 面向移动方向旋转

**构造函数**：
```csharp
public ChaseState(
    BaseEnemyController enemy, 
    Animator animator, 
    float speed = 5f,
    string runAnim = "anim_Run_Loop",
    string idleAnim = "anim_Idle_Loop_S",
    bool autoSwitchState = true,
    float pathUpdateInterval = 0.5f  // 路径更新间隔
)
```

---

### 4. `RollingState`（滚球攻击）

**适用场景**：球形怪物的冲撞攻击

**特性**：
- 加速冲向玩家
- 碰到障碍物或玩家时停止
- 攻击结束后进入硬直状态（`StaggerState`）

**构造函数**：
```csharp
public RollingState(
    BaseEnemyController enemy, 
    VisualEffect rollingVFX = null  // 可选：滚动特效
)
```

---

### 5. `ShootingState`（射击攻击）

**适用场景**：远程射击敌人（炮台、机器人等）

**特性**：
- 面向目标旋转
- 支持多枪管（多个枪口轮流射击）
- 支持动画事件驱动射击时机（或自动定时射击）
- 自动使用对象池管理子弹

**构造函数**：
```csharp
// 单枪口版本
public ShootingState(
    BaseEnemyController enemy, 
    Animator animator,
    GameObject bulletPrefab, 
    Transform bulletSpawnPoint, 
    float bulletSpeed = 10f,
    float bulletLifeTime = 3f,
    float bulletDamage = 10f,
    float bulletInterval = 0.5f,
    string shootAnim = "anim_Shoot",
    string idleAnim = "anim_Idle_Loop_S"
)

// 多枪管版本
public ShootingState(
    BaseEnemyController enemy,
    Animator animator,
    GameObject bulletPrefab,
    Transform[] bulletSpawnPoints,    // 多个枪口
    ...
    bool useAnimationEventTiming = false  // 是否由动画事件控制射击时机
)
```

**动画事件控制射击**：
- 在射击动画片段中添加事件
- 函数名：`AE_Shoot`，参数：连发次数（int）
- 或函数名：`AE_ShootMuzzle`，参数：枪口索引（int）

---

### 6. `StaggerState`（硬直/受击状态）

**适用场景**：受击后的短暂停顿，播放受击动画

**特性**：
- 在指定时间内停顿（播放动画）
- 时间结束后恢复到指定状态（默认恢复到巡逻/攻击）

**使用方法**：
```csharp
// 1. 创建硬直状态
staggerState = new StaggerState(enemyController, animator, hitTrigger: "anim_Hit");

// 2. 配置硬直时间和恢复状态
staggerState.Configure(duration: 0.5f, resumeState: attackState);

// 3. 切换到硬直状态
enemyController.StateMachine.ChangeState(staggerState);
```

## 动画事件系统

### 传统方式：专用方法

**子弹射击事件**（在 `ShootingState` 中）：

1. 在 Animator 的射击动画片段中添加事件：
   - 时间点：射击动作的关键帧（如举枪后瞬间）
   - 函数名：`AE_Shoot`
   - 参数：`1`（射击 1 发）

2. 代码会自动调用：
   ```csharp
   BaseEnemyController.AE_Shoot(1) 
   → ShootingState.RequestShootFromAnimationEvent(1)
   → ShootOnce() // 实际发射子弹
   ```

**多枪管射击**：
- 函数名：`AE_ShootMuzzle`
- 参数：枪口索引（0/1/2...）

---

### 新方式：通用动画事件 **[推荐用于Boss]**

**适用场景**：需要精确控制攻击判定窗口、位移、无敌帧的复杂动作

**使用步骤**：

1. **让状态实现 `IAnimationEventReceiver` 接口**：
   ```csharp
   public class MyBossAttackState : IState, IAnimationEventReceiver
   {
       private bool _hitboxActive = false;
       
       public void OnAnimationEvent(string eventKey)
       {
           switch (eventKey)
           {
               case "HitStart":
                   _hitboxActive = true;
                   Debug.Log("开启攻击判定");
                   break;
               case "HitEnd":
                   _hitboxActive = false;
                   Debug.Log("关闭攻击判定");
                   break;
               case "Dash":
                   DoDash();
                   break;
               case "IFrameOn":
                   _isInvincible = true;
                   break;
               case "IFrameOff":
                   _isInvincible = false;
                   break;
           }
       }
       
       public void OnAnimationEventInt(int eventValue)
       {
           // 处理整数事件（如连招索引、动作变种等）
       }
   }
   ```

2. **在动画片段中添加事件**：
   - 函数名：`AE`
   - 参数类型：`String`
   - 参数值：`"HitStart"` / `"HitEnd"` / `"Dash"` 等

3. **运行时流程**：
   ```
   动画播放到事件帧 
   → BaseEnemyController.AE("HitStart")
   → StateMachine.CurrentState as IAnimationEventReceiver
   → MyBossAttackState.OnAnimationEvent("HitStart")
   → 开启攻击判定
   ```

**优势**：
- 不需要为每个动作在 `BaseEnemyController` 中添加新方法
- 动画师可以在 Animator 中自由添加事件，无需修改代码
- 适合快速迭代Boss动作

## 伤害与死亡系统

### 伤害流程

```
攻击者 → 创建 AttackData → 调用 IDamageable.TakeDamage() 
→ CharacterState 扣血 → 显示血条 → 触发 OnTakeDamage 事件
→ （血量<=0）→ 触发 OnDeath 事件 → 销毁控制器 → 播放溶解动画 → 销毁对象
```

### `AttackData` 结构

```csharp
public struct AttackData 
{
    public Transform transform;  // 攻击者
    public float damage;         // 伤害值
    public bool IsWeakPoint;     // 是否命中弱点
    public bool KnockUp;         // 是否击飞
}
```

### 子弹命中伤害

`BulletBehaviour.cs` 已实现自动伤害逻辑：
```csharp
private void OnTriggerEnter(Collider other)
{
    IDamageable damageable = other.GetComponentInParent<IDamageable>();
    if (damageable != null)
    {
        damageable.TakeDamage(new AttackData(owner, 10f, false, false));
        ReturnToPool(); // 命中后归还对象池
    }
}
```

### 近战攻击伤害

在攻击状态中手动调用：
```csharp
// 示例：滚球攻击命中时
OnHit += (damageable) => {
    damageable.TakeDamage(new AttackData(enemyController.transform, 10f, false, true));
};
```

## 常见问题排查

### ❌ 问题1：怪物不移动 / 寻路失败

**可能原因**：
1. ❌ 没有烘焙 `NavMeshAsset`
2. ❌ `BaseEnemyController.nav` 字段未赋值
3. ❌ `BaseEnemyController.terrain` 字段未赋值
4. ❌ 起点/终点在地图边界外
5. ❌ 起点/终点被标记为阻挡（`CellFlag.Blocked`）

**解决方法**：
- 确保在 Inspector 中拖入 `NavMeshAsset` 和 `Terrain`
- 检查 Console 是否有 `"起点或终点在地图边界外"` 警告
- 使用调试工具可视化寻路网格（如果有）

---

### ❌ 问题2：怪物不攻击玩家

**可能原因**：
1. ❌ 场景中没有 `Player` Tag 的对象
2. ❌ `attackState` 为 `null`（没有初始化）
3. ❌ 玩家距离超出 `SightRange`
4. ❌ 状态切换逻辑有误（`_isInAttackState` 标志错误）

**解决方法**：
- 确保玩家对象的 Tag 设置为 `Player`
- 在 `Awake()` 中确认 `attackState = new ...`
- 增大 `SightRange` 测试
- 添加 Debug.Log 打印状态切换信息

---

### ❌ 问题3：怪物不掉血 / 子弹穿透

**可能原因**：
1. ❌ 怪物没有 `CharacterState` 组件
2. ❌ 怪物的 Collider 没有勾选 `Is Trigger`
3. ❌ 子弹的 Collider 没有勾选 `Is Trigger`
4. ❌ 子弹和怪物的 Layer 设置不正确（物理矩阵中被忽略）
5. ❌ 子弹 `owner` 字段没有正确设置（误判为自身碰撞）

**解决方法**：
- 确保怪物挂载 `CharacterState` 并实现 `IDamageable`
- 检查碰撞层设置（Edit → Project Settings → Physics → Layer Collision Matrix）
- 在 `ShootingState` 中设置 `bullet.owner = enemyController.transform`

---

### ❌ 问题4：动画不播放 / 动画卡住

**可能原因**：
1. ❌ `_animator` 为 `null`
2. ❌ Animator Controller 中没有对应的动画状态
3. ❌ 动画状态名称拼写错误（如 `anim_Walk_Loop` 写成了 `anim_walk_loop`）
4. ❌ Animator 的 `Culling Mode` 设置为 `Cull Completely`（怪物离屏后动画停止）

**解决方法**：
- 在 Animator Controller 中检查状态名称（大小写敏感）
- 使用 `Animator.StringToHash()` 缓存动画Hash值
- 将 Culling Mode 改为 `Always Animate`（如果需要离屏动画）

---

### ❌ 问题5：怪物卡在原地 / 抖动

**可能原因**：
1. ❌ 状态切换滞后量 `_attackHysteresis` 设置为0（边缘震荡）
2. ❌ 巡逻点设置在障碍物内部或墙外
3. ❌ 寻路格子过大，导致路径穿墙
4. ❌ 怪物与障碍物碰撞体积过大（一直处于碰撞状态）

**解决方法**：
- 设置 `_attackHysteresis = 1.5f`（进入攻击需要 `< SightRange - 1.5`，退出需要 `> SightRange + 1.5`）
- 检查巡逻点位置（确保在可行走区域）
- 调整 `NavMeshAsset.cellSize` 参数
- 缩小怪物 Collider 体积

---

### ❌ 问题6：射击不触发 / 子弹不发射

**可能原因**：
1. ❌ 动画事件函数名拼写错误（`AE_Shoot` 写成了 `AE_shoot`）
2. ❌ `bulletPrefab` 或 `bulletSpawnPoint` 未赋值
3. ❌ `useAnimationEventTiming = true` 但动画片段中没有添加事件
4. ❌ 动画事件时间点设置不合理（动画还没播放到就切换状态了）

**解决方法**：
- 检查动画片段中的事件函数名（区分大小写）
- 在 Inspector 中确认预制体和发射点已赋值
- 添加 Debug.Log 在 `AE_Shoot` 中确认调用
- 调整动画事件时间点或延长状态停留时间

## 进阶：Boss与复杂AI

### Boss 动作系统设计思路 **[新增]**

**传统做法（不推荐）**：
- 一个攻击 = 一个新 State
- Boss 有 10 个招式 = 写 10 个 State 类
- 结果：代码爆炸、难以维护

**推荐做法**：
1. **动作当模块，不当状态**：
   - Boss 只有少量大状态：`BossIdleState`、`BossCombatState`、`BossStaggerState`
   - 在 `BossCombatState` 中管理多个"动作"（Attack/Skill）

2. **用动画事件做动作窗口**：
   - 命中判定：`AE("HitStart")` 开启，`AE("HitEnd")` 关闭
   - 位移：`AE("Dash")` 触发冲刺
   - 无敌帧：`AE("IFrameOn")` / `AE("IFrameOff")`
   - 发射投射物：`AE("SpawnProjectile")`

3. **动作选择器**（Selector）：
   - 每个动作有：距离条件、冷却时间、权重、互斥标签
   - 每次攻击时从可用动作中按权重随机选择

4. **阶段系统**（Phase）：
   - 血量到阈值后切换动作表/权重/速度
   - 例如：血量 < 50% 时解锁狂暴技能，攻击速度 x1.5

**示例动作配置**（伪代码）：
```csharp
public class BossAction
{
    public string AnimationTrigger;    // 动画触发器
    public float MinDistance;          // 最小距离
    public float MaxDistance;          // 最大距离
    public float Cooldown;             // 冷却时间
    public float Weight;               // 权重（越高越容易被选中）
    public string[] RequireTags;       // 需要的标签（如 "OnGround", "HasRage"）
    public Action OnAnimationEvent;    // 响应动画事件的回调
}

// 使用
var actions = new List<BossAction>
{
    new BossAction { AnimationTrigger = "Attack_Slash", MinDistance = 0, MaxDistance = 3, Cooldown = 2f, Weight = 10 },
    new BossAction { AnimationTrigger = "Attack_Jump", MinDistance = 3, MaxDistance = 8, Cooldown = 5f, Weight = 5 },
    new BossAction { AnimationTrigger = "Attack_Beam", MinDistance = 8, MaxDistance = 20, Cooldown = 10f, Weight = 3 },
};
```

**使用新的动画事件接口**：
```csharp
public class BossCombatState : IState, IAnimationEventReceiver
{
    private BossAction _currentAction;
    
    public void OnAnimationEvent(string eventKey)
    {
        // 根据当前动作的类型处理事件
        switch (_currentAction.AnimationTrigger)
        {
            case "Attack_Slash":
                if (eventKey == "HitStart") EnableSlashHitbox();
                if (eventKey == "HitEnd") DisableSlashHitbox();
                break;
            case "Attack_Jump":
                if (eventKey == "Dash") DoJumpDash();
                if (eventKey == "Land") CreateShockwave();
                break;
        }
    }
}
```

## 性能优化建议

### 1. 对象池

**已实现**：`ObjectPool<T>` 和 `GameObjectPool`

**使用场景**：
- ✅ 子弹（高频生成销毁）
- ✅ 特效粒子
- ✅ 伤害数字 UI
- ✅ 召唤物/投射物

**使用方法**：
```csharp
// 创建对象池
private GameObjectPool _bulletPool = new GameObjectPool(
    bulletPrefab, 
    initialSize: 20,
    onGet: (go) => go.GetComponent<BulletBehaviour>()?.ResetBullet()
);

// 获取对象
GameObject bullet = _bulletPool.Get(position, rotation);

// 归还对象
_bulletPool.Return(bullet);
```

---

### 2. 异步寻路

**已实现**：`NePathFinder.FindPathAsy()`

**优势**：
- 每帧限制处理节点数量（默认 50 个）
- 避免大量怪物同时寻路导致卡顿
- 支持取消请求（`CancelPathRequest`）

**注意**：
- 不要在 `Update()` 中每帧调用 `RequestPathAsync`
- 使用 `_isPathPending` 标志避免重复请求

---

### 3. 动画优化

**建议**：
- ✅ 使用 `Animator.StringToHash()` 缓存动画Hash值
- ✅ 避免每帧调用 `CrossFade`（只在状态切换时调用）
- ✅ 使用 `Culling Mode = Cull Update Transforms`（离屏时不更新动画，但保持状态）

---

### 4. 碰撞检测优化

**建议**：
- ✅ 使用 Layer Mask 过滤不必要的碰撞检测
- ✅ 简化 Collider 形状（用 Capsule/Box 代替 Mesh Collider）
- ✅ 使用 Trigger 而非物理碰撞（子弹、攻击判定）

---

### 5. LOD（细节层次）

**建议**：
- ✅ 远距离怪物降低动画更新频率
- ✅ 远距离怪物禁用寻路（直线移动）
- ✅ 远距离怪物简化模型（使用 LOD Group）

## 附录：完整示例

### 示例1：固定点巡逻 + 滚球攻击

```csharp
public class EnemyControllerBallRobot : BaseEnemyController
{
    [Header("特效")]
    public VisualEffect RollingVFX;
    
    private float _attackHysteresis = 1.5f;
    private bool _isInAttackState = false;
    
    protected override void Awake()
    {
        base.Awake();
        patrolState = new PatrolState(this, _animator, Movespeed, autoSwitchToAttack: false);
        attackState = new RollingState(this, RollingVFX);
    }
    
    protected override void Start()
    {
        base.Start();
        if (RollingVFX != null) RollingVFX.Stop();
        StateMachine.ChangeState(patrolState);
    }
    
    protected override void Update()
    {
        base.Update();
        CheckAttackRange();
    }
    
    private void CheckAttackRange()
    {
        if (Target == null || StateMachine == null) return;
        float distance = Vector3.Distance(transform.position, Target.position);
        
        if (!_isInAttackState && distance < SightRange - _attackHysteresis)
        {
            _isInAttackState = true;
            StateMachine.ChangeState(attackState);
        }
        else if (_isInAttackState && distance > SightRange + _attackHysteresis)
        {
            _isInAttackState = false;
            StateMachine.ChangeState(patrolState);
        }
    }
}
```

### 示例3：不巡逻的炮台

```csharp
public class EnemyControllerTurret : BaseEnemyController
{
    private IState idleState;
    
    protected override void Awake()
    {
        base.Awake();
        // 不设置 patrolState
        idleState = new TurretIdleState(this, _animator);
        attackState = new RollingState(this);
    }
    
    protected override void Start()
    {
        base.Start();
        StateMachine.ChangeState(idleState); // 从待机开始
    }
}

// 炮台待机：原地旋转搜索
public class TurretIdleState : IState
{
    private BaseEnemyController _controller;
    private Animator _animator;
    private float _rotationSpeed = 30f;
    
    public TurretIdleState(BaseEnemyController controller, Animator animator)
    {
        _controller = controller;
        _animator = animator;
    }
    
    public void OnEnter() => _animator?.CrossFade(Animator.StringToHash("anim_Idle_Loop_S"), 0.1f);
    
    public void Tick()
    {
        _controller.transform.Rotate(Vector3.up, _rotationSpeed * Time.deltaTime);
        
        if (_controller.Target != null)
        {
            float distance = Vector3.Distance(_controller.transform.position, _controller.Target.position);
            if (distance < _controller.SightRange)
            {
                _controller.StateMachine.ChangeState(_controller.attackState);
            }
        }
    }
    
    public void OnExit() { }
}
```

## 总结

这套怪物系统的核心优势：

1. **模块化**：状态、寻路、伤害、对象池都是独立模块，易于测试和复用
2. **可扩展**：新增怪物类型只需继承 `BaseEnemyController` 并组装状态
3. **动画驱动**：通过动画事件精准控制攻击时机，减少硬编码
4. **异步寻路**：不卡帧，支持大量怪物同时寻路
5. **性能友好**：对象池、动画Hash缓存、协程寻路

**快速检查清单**（新怪物不工作时）：
- ✅ 场景中有 `Player` Tag 的对象
- ✅ `BaseEnemyController.nav` 和 `terrain` 已赋值
- ✅ 烘焙了 `NavMeshAsset`
- ✅ 怪物挂载了 `CharacterState` 组件
- ✅ 怪物有 Collider 且勾选了 `Is Trigger`
- ✅ Animator Controller 中有对应的动画状态
- ✅ 在 `Awake()` 中初始化了 `patrolState` 和 `attackState`
- ✅ 在 `Start()` 中调用了 `StateMachine.ChangeState(initialState)`
